# v15 版本说明

- 版本号：v15
- 基线目录（Git 工作区）：`_versioning/git-new/AI-DCP-src-v15-git/`
- 默认端口：
  - 后端：`http://127.0.0.1:8000/`
  - 前端（开发模式）：`http://127.0.0.1:5175/`

## 本次主要变更

### 1) UI 体验优化

- 全局配色与组件质感调整（更克制的按钮/输入框/卡片视觉）
- 人机评测：按钮按“选择/导入”分组并加外框，布局更清晰
- A/B Test：新建评审记录的按钮区调整为独立操作条（提示信息不挤压按钮）

### 2) 任务监控新增“重命名/备注/删除”

- 支持对历史记录进行重命名，并可填写备注（用于标记记录用途）
- 支持删除历史记录，并同时删除对应输出文件目录（用于控制数据量、只保留关注数据）

后端新增接口：

- `PUT /api/history/events/{event_id}`：更新 `title` 与 `note`（note 写入 meta）
- `DELETE /api/history/events/{event_id}?delete_files=true`：删除记录并清理输出目录（安全校验：仅允许删除 OUTPUT_DIR 下的文件/目录）

## 启动方式

### 一键启动（推荐）

双击运行：

- 启动：`tools/web/start.command`
- 停止：`tools/web/stop.command`

### 手动启动（开发/排查用）

后端：

```bash
cd backend
python3 -m venv venv
./venv/bin/pip install -r requirements.runtime.v1.txt
./venv/bin/python -m playwright install chromium
./venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

前端：

```bash
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 5175
```

## 数据目录（不入库、不上传）

- `backend/data/`：本地密钥/加密配置等
- `backend/data/data/history.db`：历史记录数据库
- `backend/data/output/`：批任务输出目录（删除历史记录时会清理该目录下对应 run_xxx）
- `backend/data/logs/`：后端日志
- `frontend/node_modules/`、`frontend/dist/`：前端依赖与构建产物

## 常见问题

### 1) macOS 上 urllib3/LibreSSL 警告

日志里看到：

`urllib3 v2 only supports OpenSSL 1.1.1+ ... LibreSSL 2.8.3`

多数情况下只是警告；若遇到 HTTPS 请求异常，建议改用 Homebrew 的 Python 后重建 venv。
