## 版本信息

- 版本号：v13
- Git 标签：`v13`
- 默认端口：
  - 后端：8000（`http://127.0.0.1:8000/`）
  - 前端：5175（`http://127.0.0.1:5175/`）

## 这一版包含什么（相对 v12）

本版本新增“批任务并发 + 限流 + 可观测 + 失败重试”，用于提升批量 JSON 输入的处理效率，同时避免撞 RPM/TPM 限制导致失败率上升。

- JSON 维度并发（可配置并发数）
- RPM/TPM 双维度限流（拿不到配额会进入等待态，不直接失败）
- 明细状态可见（包含 `waiting_rate_limit`）
- 失败项一键重试（会创建新的历史记录，不覆盖旧任务，便于追溯）

## 如何运行（macOS）

### 方式 A：一键启动（推荐）

前提：你已经完成过一次依赖安装（见下文“首次安装依赖”）。

- 启动：双击 `tools/web/start.command`
- 停止：双击 `tools/web/stop.command`

启动成功后打开：

- 前端：`http://127.0.0.1:5175/`
- 后端：`http://127.0.0.1:8000/`

日志查看：

- `./.run/backend-8000.log`
- `./.run/frontend-5175.log`

### 方式 B：手动启动（更可控，排查问题更方便）

1) 启动后端：

```bash
cd backend
./venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

2) 启动前端：

```bash
cd frontend
npm run dev -- --host 127.0.0.1 --port 5175
```

## 首次安装依赖

### 后端依赖（Python）

```bash
cd backend
python3 -m venv venv
./venv/bin/pip install -r requirements.runtime.v1.txt
./venv/bin/python -m playwright install chromium
```

### 前端依赖（Node.js）

```bash
cd frontend
npm install
```

## 并发/限流配置（重要）

### 1) 前端入口（推荐）

在「任务处理」页勾选 JSON 导入后，填写：

- JSON 并发数：建议 4-16

### 2) 环境变量（后端）

- `AI_DCP_JSON_CONCURRENCY`：默认 8（JSON 输入并发数）
- `AI_DCP_LLM_RPM_LIMIT`：默认 500（请求数/分钟）
- `AI_DCP_LLM_TPM_LIMIT`：默认 1000000（token/分钟）
- `AI_DCP_LLM_MAX_OUTPUT_TOKENS`：默认 2048（用于 TPM 的保守估算）

## 可观测与重试

- 任务队列/进度：在「历史记录」页查看
- 明细状态：
  - `running`：正在处理
  - `waiting_rate_limit`：等待限流配额
  - `success`：成功
  - `unmatched/exception`：失败
- 失败重试：在历史详情页点击「重试失败项」

## 常见问题

### 1) urllib3 / LibreSSL 警告

如果看到：

`urllib3 v2 only supports OpenSSL 1.1.1+ ... LibreSSL 2.8.3`

多数情况下只是警告；若遇到 HTTPS 请求异常，建议改用 Homebrew 的 Python 并重建 venv。
